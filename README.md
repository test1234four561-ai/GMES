# GMES
An organized repository of web-based utilities, bypass tools, bookmarklets, and lightweight web applications.

### 📦 Current Version
* **Version:** `v0.17`

---

## 📂 Categories in this repository

* **Invisible Games:** Bypasses that open games inside a clean `about:blank` window with masked page titles and icons.
* **Bookmarklets:** Custom scripts for browser tools (stealth browsers, ad-blockers, page editors, and school utility hacks).
* **OS & Emulators:** Web-based operating systems and retro emulators running directly in the browser.
* **Proxies & Unblockers:** Active web proxies to bypass restrictions.
* **AI Chatbots:** Standard and stealthy hidden AI interfaces.
* **ASCII & Music Tools:** Creative text-art generators and interactive sound boards.

---

## 🚀 How to import the bookmark file

You can easily import all these games, bookmarklets, and tools directly into your browser:

1. Download the exported `.html` bookmark file from this repository.
2. Open your browser's Bookmark Manager by pressing:
   * **Windows/Linux:** `Ctrl` + `Shift` + `O`
   * **Mac:** `Cmd` + `Option` + `B`
3. Click on the menu icon (usually the three dots in the top-right corner of the Bookmark Manager).
4. Select **Import bookmarks** (or **Import bookmarks HTML file**).
5. Choose the downloaded `.html` file to instantly add all tools and folders to your bookmark bar.
